# لاكاسا برجر — LACASA BURGER (منيو رقمي Static Website)

موقع منيو ثابت بالكامل — HTML5 + CSS3 + Vanilla JavaScript فقط.
بدون Backend، بدون قاعدة بيانات، بدون أي API خارجي، وبدون خطوة Build.
هوية بصرية داكنة فاخرة ("Premium Urban Burger")، والطلبات تُرسل مباشرة عبر رابط واتساب (`wa.me`).

## بنية المشروع

```
index.html       → الهيكل الرئيسي للصفحة (الافتتاحية، المنيو، السلة، نوافذ Bottom Sheet)
style.css        → كل التنسيقات (الألوان الداكنة، البطاقات، الحركات، الاستجابة)
script.js        → كل المنطق: المنيو، البحث، السلة، حساب أوقات الدوام، واتساب
menu.json        → بيانات المطعم والتصنيفات والمنتجات
config.js        → رقم الواتساب، رقم الهاتف، رابط الخريطة، وأوقات الدوام (مكان واحد لكل شيء)
manifest.json    → إعدادات إضافة الموقع كتطبيق على الشاشة الرئيسية (PWA خفيف)
sw.js            → Service Worker بسيط لتخزين هيكل الصفحة مؤقتاً (تجربة أسرع عند العودة)
assets/images/   → كل صور اللوجو والمنتجات
```

## تعديل أوقات الدوام ⏰

مكان واحد فقط: افتح `config.js` وعدّل القسم التالي:

```js
BUSINESS_HOURS: {
  open: "10:00",     // وقت الفتح (24 ساعة)
  close: "03:00",    // وقت الإغلاق — إن كان أصغر من وقت الفتح فهذا يعني عبور منتصف الليل تلقائياً
  timezone: "Asia/Baghdad",
  label: "من الساعة 10 صباحاً حتى 3 فجراً، يومياً", // النص المعروض داخل نافذة "حالة المطعم"
}
```

الحساب يتم دائماً بتوقيت بغداد الفعلي (عبر `Intl.DateTimeFormat`)، بغض النظر عن توقيت جهاز الزائر،
ويتحدّث تلقائياً كل دقيقة وعند العودة إلى الصفحة. زر "مفتوح الآن / مغلق الآن" بجانب أوقات الدوام
في الافتتاحية يفتح نافذة صغيرة تعرض التفاصيل فقط (لا يتحكم الزبون بحالة المطعم).

## تعديل رقم الواتساب والهاتف

في `config.js`:

```js
WHATSAPP_NUMBER: "9647811100884", // بالصيغة الدولية بدون + أو 00
PHONE_DISPLAY:   "+964 781 110 0884",
PHONE_TEL:       "+9647811100884",
MAPS_URL:        "https://maps.google.com/?q=...",
```

## إضافة أو تعديل منتج

كل المنتجات داخل `menu.json` ضمن مصفوفة `products`. كل منتج يجب أن يملك **id فريد** غير مكرر.

منتج بسعر ثابت:
```json
{
  "id": "unique-id",
  "category": "burger",
  "group": "اسم القسم الفرعي",
  "name": "اسم المنتج",
  "image": "assets/images/my-image.png",
  "price": 5000
}
```

منتج بخيارات (أحجام/أنواع) — يظهر شارة "قابل للتخصيص" و"ابتداءً من" أقل سعر تلقائياً:
```json
{
  "id": "unique-id-2",
  "category": "pizza",
  "group": "الايطالي",
  "name": "بيتزا جديدة",
  "image": "assets/images/new-pizza.png",
  "customizable": true,
  "optionsTitle": "الحجم",
  "options": [
    { "label": "صغير", "price": 6000 },
    { "label": "وسط",  "price": 8000 },
    { "label": "كبير", "price": 13000 }
  ]
}
```

لكل صنف حقل "ملاحظات" خاص به يظهر داخل نافذة الإضافة (مثل: بدون بصل)، بالإضافة إلى حقل ملاحظات عام عند إتمام الطلب.

## الرفع على GitHub Pages

1. أنشئ مستودع (Repository) جديد على GitHub.
2. ارفع كل ملفات هذا المجلد كما هي (بنفس البنية، دون تعديل المسارات).
3. من إعدادات المستودع → Pages → اختر Branch الرئيسي (main) والمجلد الجذر (/root).
4. الموقع يعمل مباشرة بدون أي إعداد إضافي — لا Build ولا تثبيت حزم.

## ملاحظات تقنية

- لا اتصال بأي قاعدة بيانات أو خادم خلفي؛ كل البيانات محلية في `menu.json`.
- السلة تُحفظ في `localStorage` في متصفح الزائر فقط، وتبقى محفوظة بين الزيارات.
- رقم الهاتف في نموذج الطلب يُقبل فقط كأرقام، بحد أقصى/أدنى 11 رقم.
- إرسال الطلب يفتح واتساب مباشرة برسالة مختصرة وجاهزة تحتوي كل تفاصيل الطلب والمجموع.
- عند إغلاق المطعم، تبقى تصفح المنيو والسلة والإرسال متاحة، مع تنبيه واضح فقط أن المطعم مغلق حالياً.
- التصميم متجاوب بالكامل (360 إلى 1440px فأكثر) ويدعم RTL بالكامل.
- الحركات تحترم إعداد "تقليل الحركة" (`prefers-reduced-motion`) في نظام تشغيل الزائر.
